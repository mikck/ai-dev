# 审核、返工和 SOP 版本

1. 在管理面提供 workspace 待审核队列。审核详情展示已完成节点和历史产物。
2. 审核可批准、终止或退回已完成的上游 Agent。退回原子地重置目标及其后继（包括当前审核），保留独立节点结果、历史产物、绑定的执行器和 Git worktree。下次执行收到审核意见。
3. 节点可声明文本文件产物，执行器从相应仓库 worktree 收集，限制路径与大小。每次结束记录单独的产物和结果。
4. SOP 支持草稿更新、不可变发布版本及版本记录。新需求使用最新发布版本，既有需求继续使用原快照。旧 SOP 安装升级时回填首版。
5. 保持 Go 二进制打包方式，使用 Go 测试验证返工、产物、版本冻结和打包后的交付流程。
