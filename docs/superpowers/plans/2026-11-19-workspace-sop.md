# Workspace SOP 与远程执行器

- 管理面拥有 SQLite 和 API。以 workspace 为边界管理 Agent、Skill、MCP、SOP；保存 SOP 时校验节点引用和依赖图。需求创建时快照 SOP 和生效的资源配置。
- 支持拖动节点调整顺序并编辑依赖。AI 对话通过队列交给执行器，返回经过同一套图校验的草稿，用户可编辑后保存。
- Agent 节点和人工审核节点共享同一任务状态机。每节点存档输出、审核意见、提交与交付链接。节点串行领取，依赖满足后按编排顺序选择，避免同时写同一个需求分支。
- 执行器通过带共享凭据的 HTTP API 主动注册、领取并回报。任务固定到保存本地 worktree 的执行器。管理面展示活动状态并支持停用。执行器准备需求专用的仓库 Git 元数据。Agent 通过 git worktree add 创建各仓库的 worktree，并在同一需求的所有仓库使用一致分支名。
- 保留原有需求的读取和历史；新 SOP 任务由远程执行器运行。保留 AI 在交付节点主动调用发布工具的方式。
- 验证 workspace 隔离、图校验、人工审核、跨节点产物、跨仓库共享分支和执行器领取与上报。
